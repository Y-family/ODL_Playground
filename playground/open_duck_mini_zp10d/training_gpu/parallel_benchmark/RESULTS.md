# ZP10D GPU 并行测试与后续训练配置

2026-10-18 用户确认：后续 ZP10D 训练默认使用 MX350 CUDA GPU、512 个并行环境。

配置：优化奖励、unroll 16、batch_size 512、每批 2 次优化；原生线程 1、单 CPU 亲和性、串行锁。JAX 关闭显存预分配，显存预算比例 1.0，按需分配。工作区实际内存预算 10,000,000,000 字节；WSL 当前约 8.2 GB，单任务及子进程继续使用 7 GB cgroup 硬限额、swap 0。

| 并行环境数 | 结果 | 预热后中位速度（环境步/秒） | 观测到的 GPU 总显存峰值（MiB） |
|---:|---|---:|---:|
| 16 | 通过 | 313.29 | 476 |
| 32 | 通过 | 436.56 | 482 |
| 128 | 通过 | 777.70 | 467 |
| 256 | 通过 | 759.17 | 472 |
| 512 | 通过 | 852.47 | 600 |
| 1024 | 通过 | 852.45 | 857 |

GPU 总显存包含显示/驱动等其它占用，采用每约 2 秒采样，数值是观测峰值。16/32 环境各只剩一轮预热后样本；128/256/512/1024 各有四轮。前两轮仍含 JAX 编译开销，已剔除。所有通过试验的模型、参考和奖励哈希一致。

512 环境实际完成 49,152 个环境步、6 轮 PPO，策略参数最大变化 0.00330744，保存 6 个检查点。后四轮速度为 849.43、859.51、853.29、851.65 步/秒，中位值 852.47。观测到 GPU 利用率最高 98%，进程内存峰值约 2.066 GB。

按该短测速度外推，3 亿环境步的训练计算约 4.07 天；评估、保存、中断另计。之前按 20.5 步/秒算出的 170 天混入编译开销，不再作为稳态估算。

测试使用现有 18-box、仅地面接触的训练近似，关闭评估；不能代替完整模型的行走验收，也不能保证收敛。后续正式训练默认保留评估。

1,024 环境短测也通过。64 环境按用户要求跳过，2,048 环境因用户选定 512 而主动停止；两者均不是容量失败。未测出显卡最大并行容量，不再继续探测上限。

runner.py 默认环境数已改为 512；默认短程预算 49,152 步、每 8,192 步保存。长训显式指定 --steps 和 --checkpoint-every，启动命令见项目 README。当前仅记录配置，未启动长期训练。

Intel 核显未加入此 CUDA 训练；CPU 参与编译与调度。当前脚本未实现 Intel/NVIDIA 或 CPU/GPU 的异构采样合并训练。

版本库保留汇总证据 `results.json`。各 envs_* 目录中的 metadata.json、metrics.jsonl、train.log、resources.jsonl 和 checkpoints/ 为本地运行产物。一次性容量搜索脚本已停止跟踪，原版本见历史提交 `846c85be`；正式训练使用 runner.py 的默认 512 环境配置。
