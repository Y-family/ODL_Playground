# 当前版本：地面支撑负载评估

日期：2026-10-17。来源 STEP SHA256：`bb9c851dfcae554653981919bf69a950febc2730c4362e562f58a0a63f7ce740`。

打印要求：PETG；外壳填充 10%，其余打印件填充 30%。壁层数、顶底层数、层高、填充图案和打印方向尚缺。填充率未直接当作密度或强度系数。

当前估计质量 **2.080 kg**，重力 **20.406 N**。沿用同步模型的估计质量，尚未用真实切片或称重更新 PETG 打印件质量。

模型保留自由基座，无焊接支撑、无施加在基座上的外力；脚与地面实际接触。每个工况从独立的 3 秒自由站姿开始，采样步长 2 ms，轨迹/离地指标 50 Hz。

站立末 2 秒平均地面竖直支撑力 **20.405362 N**；相对重量误差 **0.00323%**。

关节反力坐标/符号校验（计入独立计算的动力学方程残差）最大误差 **7.22e-16 N·m**。有限接触求解器的关节方程残差最大 **0.000237 N·m**，两者分别记录。所有工况数值警告为 0。

## 连接件强度分析交付

`CURRENT_STRUCTURAL_LOADS.json` 包含 336 个完整同时载荷状态：每个工况、每个轴分别取电机扭矩、关节合力、关节合力矩的峰值时刻，保留姿态及父/子两侧反向载荷。坐标已映回正式 STEP，单位 N、N·mm、mm；映射轴心最大误差 6.42e-13 mm。

优先检查膝部/髋部连接及薄板、trunk_top 壳体固定区和 S01/S06 单轴输出固定面，其次颈部双板、head_pitch_to_yaw 和圆环接口。各部件的材料、填充率、现有网格与 hash 已列入载荷文件。

**本轮完成刚体负载评估与结构载荷准备，尚未完成局部有限元应力、挠度、层间强度或螺孔安全系数验证。** 关节总载荷不能直接全部施加在某一片支架上；下一步需确认螺钉承压面、接触面及多连接件分载，结合打印方向/壁层和 PETG 实际材料数据建立局部模型。

## 范围与复现

正式 CAD、MuJoCo XML 和网格未修改。碰撞代理、同刚体/直接父子过滤及软接触仍有上一阶段记录的局限，不提供全机 0.2 mm 间隙认证。地面摩擦/接触参数沿用模型估计，须对 PETG 脚底实测校准。

资源：单进程地址空间硬限 4 GB，本轮已记录的峰值 RSS 1.361 GB，观察到 1 个进程线程，串行执行。

```bash
.venv/bin/python scripts/cad/run_memory_limited.py scripts/cad/assess_zp10d_loads.py
```

JSON 保存完整轨迹与同一时刻载荷；CSV 汇总各轴；PNG 为科学绘图。打印设置缺失处保持未知，未替用户决定。
